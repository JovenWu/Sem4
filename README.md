# Inventory Forecasting Web App with POS Functionality

Welcome to your Inventory Forecasting Web Application! This project is designed to help businesses manage their inventory more efficiently by utilizing machine learning to forecast stock levels and includes a Point-Of-Sale (POS) system for daily transactions.

## Features

- **Inventory Forecasting:**  
  Leverages machine learning algorithms to predict future inventory needs based on historical sales data.

- **POS System:**  
  Includes a user-friendly POS interface for managing sales, tracking transactions, and updating inventory in real-time.

- **Web-based Application:**  
  Easily accessible from any device with a web browser.

- **Dashboard & Reporting:**  
  Visual dashboards for inventory status, sales analytics, and forecast trends.

- **User Management:**  
  Secure authentication and role-based access control.

## Tech Stack

- **Frontend:** JavaScript (React)
- **Backend:** Python (Django)
- **Machine Learning:** Python (scikit-learn, pandas)
- **Database:** (PostgreSQL)
- **Other:** REST API

## Getting Started

### Prerequisites

- Node.js & npm
- Python 3.x

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/JovenWu/Sem4.git
   cd Sem4
   ```

2. **Backend setup:**
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

3. **Frontend setup:**
   ```bash
   cd frontend
   npm install
   ```

4. **Run the app:**
   - Start the backend:
     ```bash
     python app.py
     ```
   - Start the frontend:
     ```bash
     npm start
     ```

## Usage

- Access the web app via your browser at `http://localhost:3000` (or your configured port).
- Use the POS interface for sales, and monitor your inventory forecasts on the dashboard.
